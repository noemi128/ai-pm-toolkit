## 💡 What is a "skill"?

A skill is **not code**. It's a structured Markdown file (`SKILL.md`) that teaches an AI agent — like Claude Code — how to execute a workflow the way *you* would: the steps, the order, the quality bar, and the rules it must never break.

If you can write a good process document for a new team member, you can write a skill. That's the entire barrier to entry.

## 🚀 How to use a skill

1. Copy the skill folder (e.g., `skills/interview-prep/`) into your Claude Code skills directory:
   - **Personal (all projects):** `~/.claude/skills/`
   - **Per project:** `<your-project>/.claude/skills/`
2. Start a new Claude Code session.
3. Invoke it naturally (*"prepare me for this interview: [job URL]"*) or explicitly with `/interview-prep`.

Skills are plain Markdown — open them, read them, adapt them to your own process. That's the point.

## 🧭 Principles behind these skills

- **Workflows beat prompts.** A conversation you keep having should become a process that runs itself.
- **Encode values, not just steps.** My skills include non-negotiables like *"never inflate a verdict"* and *"never invent experience"* — an AI agent amplifies whatever standards you give it.
- **Honest output over pleasant output.** A flattering analysis that fails in the real world is a bug, not a feature.
